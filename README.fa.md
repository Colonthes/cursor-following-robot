# ربات دنبال‌کننده نشانگر

یک شخصیت سه‌بعدی تعاملی برای وب‌سایت، ساخته‌شده با Three.js. این پروژه برای وب‌سایت پادیسار توسعه یافته و شامل **کد پایه قابل ویرایش، نسخه نمایشی مستقل و افزونه قابل نصب وردپرس** است.

[English](README.md) · [راهنمای کامل فارسی وردپرس و انفولد](docs/wordpress.fa.md)

## امکانات

- دنبال‌کردن نشانگر با سر، در کل صفحه یا یک بخش مشخص.
- واکنش به کلیک روی سر، دست‌ها و پاها؛ همراه با حرکت هماهنگ مالیدن دست.
- بازکردن گفت‌وگوی پشتیبانی موجود با کلیک روی سینه.
- حرکت دهان و دست‌ها هنگام نمایش پاسخ دستیار در گفت‌وگوی متصل.
- پس‌زمینه شفاف و تصویر ثابت برای دستگاه‌های لمسی و حالت کاهش حرکت.
- توقف رندر در خارج از دید و زبانه مخفی؛ حداکثر ۳۰ فریم در ثانیه.

این پروژه چت‌بات، سرویس هوش مصنوعی یا صدای گفتاری تولید نمی‌کند. نسخه نمایشی از پاسخ‌های نمونه محلی استفاده می‌کند و به کلید API نیاز ندارد.

## نصب در وردپرس

۱. فایل **[padisar-robot.zip](https://github.com/Colonthes/cursor-following-robot/raw/refs/heads/main/downloads/padisar-robot.zip)** را دانلود کنید و از حالت فشرده خارج نکنید.

۲. از مسیر «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه»، آن را نصب و فعال کنید.

۳. کد زیر را در بلوک «کد کوتاه» وردپرس یا Text Block انفولد قرار دهید:

```text
[padisar_robot height="560" accent="#06b6d4" tracking="page" idle="true"]
```

۴. صفحه اصلی سایت را مشاهده کنید و در صورت باقی‌ماندن نسخه قدیمی، کش انفولد، افزونه‌های کش، CDN و مرورگر را پاک کنید.

حداقل نسخه‌های اعلام‌شده در افزونه: وردپرس ۶ و PHP ۷٫۴. فایل ZIP کامل مخزن گیت‌هاب با بسته نصب افزونه متفاوت است؛ برای نصب از لینک بالا استفاده کنید.

## اجرای نسخه نمایشی و توسعه

پس از دانلود مخزن، فایل `docs/demo-and-guide.html` را در مرورگر باز کنید. این فایل مستقل است و منابع مورد نیاز خود را درون فایل دارد.

برای ویرایش کد، Node.js نسخه ۲۲ یا بالاتر لازم است. ساخت ZIP افزونه به Python 3 نیاز دارد:

```bash
npm ci
npm test
npm run build
npm run package
```

کد مدل در `src/model.js`، حرکت در `src/motion.js`، رندر و انتخاب اجزای بدن در `src/robot.js` و اتصال گفت‌وگو در `assets/chat-bridge.js` قرار دارد.

## اتصال گفت‌وگو و محدودیت‌ها

اتصال پیش‌فرض برای نشانگرهای DOM افزونه Site Chatbot نوشته شده است. تغییر دو گزینه `chat_selector` و `chat_panel` فقط بازکردن پنجره را تنظیم می‌کند؛ هماهنگ‌سازی پاسخ یک چت‌بات دیگر به اتصال رویدادها یا آداپتور اختصاصی نیاز دارد.

آزمایش نصب واقعی روی وردپرس و انفولد در زمان آماده‌سازی این مخزن انجام نشده است. پیش از استفاده در سایت اصلی، مسیر واقعی گفت‌وگو، دسترسی با صفحه‌کلید، نسخه موبایل و تنظیمات کش را در محیط آزمایشی بررسی کنید. [گزارش اعتبارسنجی](docs/validation.md) وضعیت آزمون‌ها را توضیح می‌دهد.

مجوز کد MIT است. لوگو و نشان‌های تجاری پادیسار متعلق به صاحب اثر هستند و در مجوز کد قرار نمی‌گیرند؛ برای استفاده در برند دیگر، آن‌ها را با آثار دارای مجوز خود جایگزین کنید.
