INTERACTIVE 3D COMPANION

A little character.
A more human interface.

Move your pointer and try the hands, head, and legs. Activate the chest to open the local sample chat, then send a message to see its reply gestures.

Installation guide

Built entirely from code, with a plain chest and transparent background. Touch and reduced-motion visitors get a static poster with the same chest action.

WordPress and plain HTML

Download cursor-robot.zip, upload it in Plugins → Add New Plugin, and activate Cursor Following Robot.

Add [cursor_robot height="560" tracking="page"] to a Shortcode block or Enfold Text Block.

Full WordPress guide · Source and plain HTML setup

The robot connects to an existing chat provider. This demo supplies local sample replies, with no AI service or voice audio.

راهنمای نصب

بسته cursor-robot.zip را از بخش افزونه‌ها بارگذاری و فعال کنید. سپس کد زیر را در بلوک کد کوتاه وردپرس یا Text Block انفولد قرار دهید:
