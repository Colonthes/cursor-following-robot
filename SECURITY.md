# Security

This plugin provides browser animation and a WordPress shortcode. It has no account system, API keys, database tables, or AI backend. Existing chat widgets retain their own data handling and security responsibilities.

For a suspected vulnerability, use the repository's private vulnerability reporting feature if available. If it is unavailable, open a minimal issue asking for a private reporting channel; do not publish exploit details, credentials, personal data, or production logs.

Include the version, affected integration, reproduction conditions, and impact in the private report. No response-time or long-term-support guarantee is made.
