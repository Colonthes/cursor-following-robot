# Changelog

## 1.4.0 — GitHub project packaging, 2026-10-19

- Published the recovered v1.4.0 base source, assets, and WordPress shortcode in one repository.
- Added a minimal HTML integration example and kept the self-contained bilingual demo.
- Added an installable WordPress ZIP and a reproducible packaging script.
- Added English/Persian entry guides, architecture and integration notes, contribution guidance, and dependency notices.
- Added runnable tests and an automated checks workflow.
- Preserved the original robot runtime and behavior; the plugin header now links to this repository.

- Transparent robot with original Padisar chest branding.
- Head tracking, subtle hand proximity, and hand/head/leg click reactions.
- Existing chat launcher integration and visual assistant-reply gestures.
- Static touch/reduced-motion fallback with a native chest action.

Historical validation records are retained in `docs/archive/` and are distinguished from current runnable checks.
