# Changelog

## 1.5.0 — 2026-10-19

- Shipped a neutral robot with a plain chest and a freshly rendered transparent poster.
- Standardized the browser namespace on `CursorRobot`, CSS/events on `cursor-robot`, and the WordPress shortcode on `[cursor_robot]`.
- Removed external logo assets, texture-loading code, obsolete packages, and superseded records.
- Rebuilt the browser bundle, self-contained bilingual demo, and `cursor-robot.zip` installation package.
- Kept head tracking, body reactions, existing-chat integration, keyboard access, and static fallback behavior.

### Upgrade

The plugin folder and shortcode use new names. Deactivate an earlier installation, install the current package, and update the page shortcode to `[cursor_robot]`.
